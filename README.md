### Use Case 6: Booking History & Reporting

In this use case the admin stores the Booking History and saves it, when required the admin can make a report of the history.


Data Structure used -> List


##### Key Requirements

Store confirmed reservations

Support cancellation & review

Generate reports


Goal was to -> Maintain complete booking history.


Actors ware -> Admin, Reporting Service

Flow was -> Confirm booking → Add to List → Persist → Retrieve when needed
